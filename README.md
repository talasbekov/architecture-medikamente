# architecture-medikamente

Проектная работа 10 спринта. Кейс медицинского центра «Медикаменте»: приведение работы с конфиденциальными данными и ПДн в соответствие требованиям законодательства РФ, проектирование целевой архитектуры по подходу Privacy by Design и планирование миграции с ручных процессов на единую информационную систему.

## Как смотреть диаграммы

Все диаграммы — в формате `.drawio.xml`. Открываются в [app.diagrams.net](https://app.diagrams.net) через **File → Open From → Device** или в desktop-версии draw.io. В файлах с несколькими диаграммами они разложены по вкладкам внизу окна.

Рядом с каждой диаграммой лежит `.md` с текстовым описанием — можно читать, не открывая draw.io.

## Сквозные обозначения

| Обозначение | Значение |
|---|---|
| C0 … C4 | Классы конфиденциальности: публичные, внутренние, ПДн, строго конфиденциальные (медицинские), секреты |
| Р-01 … Р-42 | Идентификаторы проблемных зон из Task1. Используются во всех документах и на диаграммах As-Is |
| Н-01 … Н-14 | Конфиденциальные данные, не учтённые ни в одной системе (Task1, раздел 2.2) |
| 🆕 | На диаграммах C4 — блоки, которых нет в текущей архитектуре |

## Нормативная база

- № 152-ФЗ «О персональных данных» — ст. 5, 6, 7, 9, 10, 11, 14, 18.1, 19, 20, 21, 22, 22.1
- № 323-ФЗ «Об основах охраны здоровья граждан в РФ», ст. 13 — врачебная тайна
- Постановление Правительства РФ № 1119 — уровни защищённости ИСПДн
- Приказ ФСТЭК России № 21 — состав и содержание мер по обеспечению безопасности ПДн
- Приказ ФСБ России № 378 — требования к СКЗИ в ИСПДн
- № 63-ФЗ «Об электронной подписи»
- № 242-ФЗ — локализация баз данных с ПДн граждан РФ на территории РФ
