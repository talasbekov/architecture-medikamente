# architecture-medikamente

Проектная работа 10 спринта. Кейс медицинского центра «Медикаменте»: приведение работы с конфиденциальными данными и ПДн в соответствие требованиям законодательства РФ, проектирование целевой архитектуры и планирование миграции.

## Структура репозитория

| Директория | Что внутри |
|---|---|
| [Task1](Task1) | Анализ безопасности системы As-Is: диаграммы потоков данных (DFD) по процессам, список проблемных зон, реестр данных для защиты, механизм тегирования, доработанные To-Be диаграммы |
| [Task2](Task2) | Целевая архитектура в модели C4 (контекст + контейнеры) с блоками Privacy by Design и аналитическим слоем |
| [Task3](Task3) | Классификация данных, обоснование защиты по классам, инструменты защиты at rest / in transit, реестр программных и аппаратных средств |
| [Task4](Task4) | Диаграмма Исикавы по узким местам миграции и отчёт с рекомендациями |
| [Task5](Task5) | Обоснование выбора стратегии миграции, cutover-план, управление рисками и распределение ролей |
| [Task6](Task6) | Движок классификации данных перед загрузкой в хранилище: диаграмма C2, метрики, масштабирование |

## Как смотреть диаграммы

Все диаграммы — в формате `.drawio.xml`. Открываются в [app.diagrams.net](https://app.diagrams.net) (File → Open From → Device) или в desktop-версии draw.io. В файлах с несколькими процессами диаграммы разложены по вкладкам внизу окна.

Для удобства ревью рядом с каждой диаграммой лежит `.md` с текстовым описанием того, что на ней изображено.

## Нормативная база, на которую я опирался

- № 152-ФЗ «О персональных данных»
- № 323-ФЗ «Об основах охраны здоровья граждан в РФ», ст. 13 — врачебная тайна
- Постановление Правительства РФ № 1119 — уровни защищённости ИСПДн
- Приказ ФСТЭК России № 21 — состав и содержание организационных и технических мер
- Приказ ФСБ России № 378 — требования к СКЗИ в ИСПДн
- № 63-ФЗ «Об электронной подписи»
- № 242-ФЗ — локализация баз данных с ПДн граждан РФ на территории РФ
